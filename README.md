# LARAM — LAndslide Risk Assessment and Mitigation

Archivio statico del sito della **LARAM School** (Università degli Studi di Salerno),
originariamente pubblicato su `www.laram.unisa.it`.

Contiene le pagine delle edizioni della School (2006–2027), dei Workshop, delle
iniziative, della community e dell'organizzazione.

## Struttura

| Cartella | Contenuto |
|---|---|
| `laram/` | Pagine del sito (home: `laram/index.html`) |
| `www.unisa.it/`, `www3.unisa.it/` | Immagini e documenti ospitati sul portale di Ateneo |
| `index.html` | Reindirizza alla home del sito |

## Pubblicazione

Il sito è statico: si pubblica con GitHub Pages
(*Settings → Pages → Deploy from a branch → `main` / root*).
